type_clipboard_config.json

— 

        

          
        

        
Save as ~/.hammerspoon/type_clipboard_config.json. It is read fresh on every paste, so there is no need to reload Hammerspoon. Delete the file to go back to defaults.

      

    

  


  

    Every value here maps to a key the script reads. Anything you leave alone is
    simply absent from the file and falls back to the built-in default, so a
    partial config is perfectly valid — {"mistakes":{"chance":0.5}}
    is a complete, working config file.
